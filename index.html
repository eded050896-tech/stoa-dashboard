Methodology & sources

  • Swaps: every Routed event from StoaRouter 0x2F2804fad735a38015650f32f95Ad5E08D6B3eE5 on Robinhood Chain (4663), fetched with eth_getLogs on the public RPC https://rpc.mainnet.chain.robinhood.com. A failed swap reverts and emits nothing, so every event is a settled swap. Script: scripts/fetch-routed.py (data in data/routed-robinhood.json).
  • USD value: Stoa's own /api/stats value when the swap is in its 20 most recent; otherwise the USDG side (USDG = $1), otherwise the ETH side at the router's live ETH→USDG quote. Same method Stoa documents on stoadex.com/stats. No swap is unpriced in this dataset.
  • Venue names: verified against Stoa's public repo (StoaDex/Stoa) and the quote API — Uniswap V3 (quote API), Uniswap V4 adapter v1/v2 (deploy scripts), Aero Slipstream & Ramses (CLTickSpacingAdapter, factory addresses in VenuesRobinhood.sol). One adapter (0x58c2…, 2 swaps) could not be identified from public sources and is labelled as unidentified, not guessed.

  • Honest small numbers: Stoa on Robinhood Chain is days old — 33 swaps, ~$685 total at generation time. That includes the team's own launch checks (Stoa says so on its stats page). Nothing here is inflated; zeros are shown as zeros.
  • Live data: this page tries to fetch https://stoadex.com/api/stats for fresh headline totals, but Stoa's API sends no CORS headers, so a browser on another origin cannot read it — the page then uses the bundled snapshot (regenerated by scripts/refresh.sh). The venue breakdown always comes from the on-chain snapshot, because the stats API does not publish venues.
